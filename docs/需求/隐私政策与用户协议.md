> 本平台面向重庆工程学院计算机专业学生，实行学籍核验注册制（仅限本校）。
> 使用本平台即表示同意本政策；重大变更将通过站内通知告知。

## 第一部分：隐私政策

### 1. 我们收集的信息

| 类别 | 字段 | 必要性 | 存储方式 |
|------|------|--------|----------|
| 身份标识 | 学号（9 位数字） | **必选**——学籍核验注册的前提（F-ACC-004） | AES-GCM 加密（`student_id_enc`）+ HMAC-SHA256 哈希（`student_id_hash`，一号一账号） |
| 联系方式 | 邮箱 或 手机号（二选一，CR-093 起支持双渠道） | **必选**——登录与验证码投递 | AES-GCM 加密（`email_enc` / `phone_enc`）+ HMAC 哈希（等值查询） |
| 社区展示 | 昵称（2~32 字符） | **必选**——社区认人 | 明文 |
| 社区展示 | 头像、学校、专业、年级、签名 | 可选（资料编辑 F-ACC-007a） | 明文（头像 URL 可空） |
| UGC 内容 | 帖子正文（Markdown 源文 + 服务端渲染 HTML）、回复内容 | 使用功能即产生 | 明文（服务端渲染时做 XSS 白名单净化） |
| 社区关系 | 点赞 / 收藏 / 关注（关系对） | 使用功能即产生 | 明文（关系表） |
| 使用数据 | 帖子阅读数 | 使用功能即产生 | Redis 计数（同账号每日去重，IP 参与哈希） |

**不收集**：真实姓名不落 users 表（名册表内明文仅用于核验容错比对）；身份证号、家庭住址、精确地理位置、通讯录、相册等敏感个人信息**一律不收集**。

### 2. 我们如何使用信息

- **学籍核验**：学号 + 姓名与教务名册比对，通过后签发一次性核验票据（5 分钟有效）。三种失败（学号不存在 / 姓名不匹配 / 已注册）统一提示，防名册枚举。
- **登录验证**：向注册渠道（邮箱或手机号）发送 6 位验证码；验证码在服务端只存 HMAC 哈希（5 分钟过期，单号日上限 10 条、60s 重发间隔）。
- **内容展示**：昵称、头像、帖子 / 回复内容在社区内公开可见。
- **内容安全机审**：帖子 / 回复发布前经服务端机审网关（当前开发环境为日志通道；生产将接入第三方服务商），命中风险即拒绝发布。
- **阅读统计**：帖子阅读数按"每帖每账号每日 +1"去重计数，匿名访客按 IP 哈希参与去重。
- **注销与匿名化**：注销进入 7 天冷静期（期内登录即撤销注销）；期满由定时任务清除邮箱、手机号、学号（加密与哈希形态）、头像，昵称置占位文案，匿名化标记置位。**此操作不可逆**。

### 3. 我们如何保护信息

- **加密存储**：邮箱、手机号、学号采用 AES-GCM 对称加密（`*_enc` 列），等值查询使用 HMAC-SHA256（`*_hash` 列）。加密密钥（`APP_CRYPT_KEY`）与哈希密钥（`APP_HASH_KEY`）独立，生产环境必须从环境变量注入，不得使用开发默认值（启动守卫 `ProductionSafetyGuard` 强制校验）。
- **传输安全**：生产环境部署须启用 HTTPS（部署形态确定后执行）。
- **访问控制**：管理端接口（名册导入、内容处置、用户封禁）要求超级管理员角色（`ROLE_SUPERADMIN`），框架级注解 + 守护测试双重强制。
- **数据最小化**：对外接口（`UserVo`）不含邮箱、手机号、学号的明文与加密形态；学号对全站不可见（仅"是否通过核验"布尔值）。
- **安全渲染**：用户提交的 Markdown 在服务端经 flexmark + jsoup 白名单净化后生成 HTML，前端不做二次渲染（XSS 防线单点收敛）。

### 4. 我们不会做的事

- 不向任何第三方出售、出租或以其他方式交易您的个人信息。
- 不在社区内公开您的邮箱、手机号、学号（加密与哈希形态亦不出接口）。
- 不使用您的个人信息进行自动化决策或用户画像推荐。

### 5. 您的权利

- **访问与更正**：通过设置页编辑昵称、专业、签名等资料字段。
- **注销**：设置页发起注销 → 7 天冷静期（期内登录自动撤销）→ 期满自动匿名化。
- **内容删除**：帖子作者可自行删除帖子（软删，前台不可见）。
- **投诉与反馈**：通过站内举报或联系平台管理员。

### 6. 政策变更

重大变更将通过站内通知告知。历史版本由 git 版本控制追溯。

## 第二部分：用户协议

### 1. 服务性质

本平台是面向重庆工程学院计算机专业学生的校内学习交流论坛，实行学籍核验注册制。注册即表示您为本校在读学生且同意遵守本协议。

### 2. 账号规则

- 账号限本人使用，不得出借、转让或以任何方式供他人使用。
- 昵称不得冒用他人身份、含广告引流或违反社区规范（服务端字符集禁则 + 后续机审词表把关）。
- 连续违规经管理员封禁后，封禁期间不得登录或发布内容。

### 3. 社区规范

- **禁止发布**：法律法规禁止的内容；人身攻击、骚扰、歧视；广告、引流、刷屏；侵犯他人知识产权的内容；泄露他人隐私。
- **版块规则**：请在对应版块发帖（技术问答 / 学习资源 / 面经求职 / 竞赛交流 / 课程交流 / 闲聊灌水）；技术问答帖可采纳最佳答案。
- **处置机制**：违规内容经举报核实后将被下架；情节严重者封禁账号。处置全程留审计日志。

### 4. 知识产权

- 您发布的帖子 / 回复的著作权归您本人所有；发布即授予本平台在站内展示、检索与缓存的权利。
- 您引用他人内容应遵守"合理使用"原则并注明来源。

### 5. 免责声明

- 本平台是学生课程实践项目，不承诺 7×24 小时可用性；因不可抗力或系统维护导致的服务中断不构成违约。
- 用户发布的内容不代表平台立场；平台对 UGC 内容承担"通知-删除"义务。

### 6. 协议终止

您可随时通过设置页注销账号（7 天冷静期 + 匿名化）；平台可在您严重违规时封禁账号。
