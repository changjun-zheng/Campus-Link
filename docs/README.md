# Campus-Link 文档中心

文档按需阅读。当前工作入口是[变更台账 §1](变更日志/变更台账.md#1-变更汇总)与[进度驾驶舱](进度驾驶舱.html)；执行规则见 [AGENTS.md](../AGENTS.md)。

## 1. 阅读与维护规则

- 开工：查看任务相关的最新 CR，再读对应需求与设计；无需通读历史计划、纪要与全部规范。
- 当前状态：台账为事实入口，驾驶舱为聚合视图；本索引不维护阶段状态或待办副本。
- 版本：各文件头部声明版本，本页 §2 同步登记；交叉引用只写链接。
- 记录：只留当前结论、关键理由、必要验收结果和遗留风险；同一证据只保存一处。
- 历史：旧计划与评审结论按需追溯，不作为当前任务清单。精简前入口内容见[历史快照](变更日志/2026-11-03-流程精简前入口快照.md)。
