## 4. 发布、编辑与搜索链路

1. 「提问」→ 输入标题和 Markdown → 等待「草稿已保存到此浏览器」→ 刷新：标题、正文恢复，并显示恢复提示。
2. 从恢复后的表单添加标签、修改标题后发布 → 自动回跳 `/post/400135`，标题、正文、标签与三个目录项正确；再次点「提问」时标题为空且没有已发布草稿恢复提示。
3. 从该帖「编辑」入口进入 → 原标题、正文、标签预填；没有新帖草稿状态 → 修改标题与标签 → 保存 → 回跳同一详情，展示修改结果。
4. 为避免自然语言全文检索的共同词片段干扰负向断言，最终以不出现在标题或正文中的独立标签验证：替换前 `qzxqzx` 搜索命中 **1 条**；替换为 `vkjvkj` 后，新标签命中 **1 条**，旧标签显示「没有找到与 qzxqzx 相关的帖子」。不是只验写入成功。

搜索截图：[新标签命中](界面优化-CR185/search-new-tag.jpg) · [旧标签不再命中](界面优化-CR185/search-old-tag.jpg)。

数据边界：新增并保留 **1 条本机合成验收帖**（ID `400135`，最终标题「CR185 阅读与发布回归样例 已编辑」，标签 `vkjvkj`）；没有修改其他既有帖正文，也没有执行清库或文件删除。故障场景只在该浏览器留下合成草稿，不产生额外服务端帖子。草稿沿用既有字段：版块、标题、正文；不保存标签与匿名选项，页面底部已明确保存范围。

## 5. 故障回归与复现

本机 `npm run dev` 后访问 `http://localhost:5173/scripts/ui-regression-harness.html`。夹具从真实发布页启动，页面底部开关只作用于当前文档；沿用相同 CSP。模拟提交失败时不向后端发送提交，其他未模拟调用仍走真实服务。普通重新导航会退出夹具。

| 场景 | 实际操作与证据 | 结果 |
|------|----------------|------|
| 存储失败 | 勾选「草稿存储失败」，输入标题和正文；等待 2s 防抖保存与重试 | 显示「草稿保存失败，请保留页面并复制正文」，没有谎报成功 |
| 存储恢复 | 取消上述开关，再改标题 | 显示保存成功，正文仍在 |
| 防重与提交失败 | 勾选「提交失败」，双击发布 | 夹具计数 **1**；503 提示后标题、正文完整保留，按钮恢复可用 |
| 预览失败 | 勾选「预览失败」，修改正文 | 显示预览失败，编辑器仍可用 |
| 迟到响应 | 取消失败、勾选「延迟预览」；修改正文，待请求计数增加后立即清空；响应延迟 1800ms 后复查 | 迟到标题为 0、空内容提示仍在、`aria-busy=false` |
