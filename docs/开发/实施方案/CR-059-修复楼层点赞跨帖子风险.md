## 1. 目标

修复楼层点赞接口忽略路径 `postId` 的问题，确保只有当 `replyId` 确实属于路径指定的可见帖子时，才允许执行点赞 / 取消点赞。

## 2. 范围

- **做**：
  - `ReplyController` 将 `postId` 传入互动 application 服务；
  - application 层校验父帖存在且可见、回复存在且归属该父帖；
  - 跨帖子请求统一返回现有 `NOT_FOUND / 3001` 语义；
  - 补 controller 透传测试和 application 跨帖子拒绝测试。
- **不做**：
  - 不处理 `BUG-002` 的 `Reply.status` 过滤问题；
  - 不新增接口路径、请求参数或响应字段；
  - 不修改数据库、Flyway 迁移、OpenAPI 快照；
  - 不改变正常点赞、取消点赞、通知和计数逻辑。

## 5. 验证

- **单测**：
  - 同帖 `postId=9, replyId=11`：继续正常 toggle；
  - 跨帖 `postId=9, replyId=11` 且回复属于帖子 8：返回 `NOT_FOUND`，不调用点赞仓储、计数更新或通知；
  - 父帖不存在 / 已下架：返回 `NOT_FOUND`，不触发回复点赞。
- **契约**：接口路径、请求参数和响应结构不变，`openapi.json` 预期无 diff。
- **回归面**：帖子点赞、收藏、通知、自触发抑制和匿名 401 行为不变。
