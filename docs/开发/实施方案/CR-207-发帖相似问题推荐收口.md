## 1. 目标

把已在后端就位、但前端未按规范落地的「发帖时相似问题推荐」补齐并修通：标题输入时展示站内相似帖（版块、回复数、采纳标记、相对时间），无结果时给轻量空态；同时修复该接口必然 500 的后端缺陷。

## 2. 范围

- **做**：`PublishView` 推荐块视觉与信息层级对齐设计令牌；查询状态机补「成功空结果 / 失败静默 / 忽略后下次查询恢复 / 在途响应作废」；`PostMapper.findSimilar` 动态 SQL 补 `<script>`；补动态 SQL 静态守护测试。
- **不做**：不改接口路径 / 参数 / 返回形状；不改后端推荐算法、阈值与限流；不新增迁移与依赖；不处理其他页面的同类推荐。

## 3. 改动点（文件级）

| 文件 | 动作 | 说明 |
|------|------|------|
| `frontend/src/views/PublishView.vue` | 改 | 推荐块改用令牌样式与语义标签；展示 `boardName · replyCount 回复 · 相对时间`；补空态、忽略与请求序号前置 |
| `backend/src/main/java/com/campuslink/module/forum/infrastructure/persistence/mapper/PostMapper.java` | 改 | `findSimilar` 的 `@Select` 整体包 `<script>`，与 `search` 一致 |
| `backend/src/test/java/com/campuslink/module/forum/infrastructure/persistence/mapper/PostMapperSqlTest.java` | 改 | 新增「含 `<if>` / `<foreach>` 的 `@Select` 必须 `<script>` 包裹」守护用例 |

## 5. 验证

- **单测**：`PostMapperSqlTest` 5 例全绿（新增守护用例覆盖 `search` / `findSimilar`）。
- **真机**：`GET /api/v1/posts/similar` 修复前 500 / 9999，修复后 200 且返回真实相似帖；浏览器实测结果块 3 条、采纳标记 2 个、空态文案命中，控制台无报错。
- **契约**：路径 / 参数 / 响应形状未变，快照应无 diff。
- **回归面**：搜索 `PostMapper.search` 的 `<script>` 结构不变；发布页编辑模式仍不触发查询。

## 6. 回滚

`git revert` 本 CR 提交即可；无迁移、无数据变更、无开关依赖。若仅需止血后端，可单独回退 `PostMapper` 一处（前端推荐块随之静默隐藏）。

## 7. 实施结果（实施后追加，不回改上文）

- 后端缺陷为 CR-077 遗留：原有单测用 Mockito 替身，未执行注解 SQL；新增守护用例在缺 `<script>` 时会直接失败。
- 浏览器验收：1440×900，结果块显示 3 条（含版块 / 回复数 / 相对时间 / 2 个「已采纳」标签），第二次查询返回空态「暂未找到相似问题，可直接发布」。
- 未测项：窄屏下推荐块换行表现（仅桌面实测）；服务端限流未接（前端最多 2 次为当前唯一约束）。
