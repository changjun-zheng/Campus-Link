## 1. 目标

用户可以单向拉黑他人：**被拉黑者的帖子与楼层不再出现在拉黑者的列表 / 搜索 / 详情中，不能关注拉黑者，也不会给拉黑者产生任何通知**；设置页可查看黑名单并解除。被拉黑者无感知（不通知、不暴露拉黑事实）。

## 2. 范围

**做**：

- 新表 `user_blocks(blocker_id, blocked_id, created_at)`，主键 `(blocker_id, blocked_id)`（重复拉黑天然幂等），`idx_blocked` 支撑反向查询。
- 四个受保护端点：`POST /users/{targetId}/block`、`DELETE /users/{targetId}/block`、`GET /users/{targetId}/block-state`、`GET /users/me/blocks?page=&size=`。
- 读取侧过滤（一次取 `blockedIds` 集合，不逐帖查）：帖子列表 / 搜索 / 关注 Feed / 他人主页帖子流 / 楼层列表 / 帖子详情（作者被拉黑 → `3001`）。
- 互动侧阻断：被拉黑者**不能关注**拉黑者、**不能回帖 / 点赞 / 收藏**拉黑者的帖子或楼层（统一 `4002`，不提示"你被拉黑"）。
- 通知侧抑制：通知生成前检查 `blocker 是否拉黑 actor`，命中则不生成。
- 前端：他人主页「拉黑 / 已拉黑」按钮；设置页新增「黑名单」区块（列表 + 解除）。

**不做（逐条给理由）**：

- **私信约束**：F-SOC-003 私信尚未实现，等私信 CR 一起接。
- **双向拉黑 / 拉黑通知**：PRD 只写"拉黑 / 屏蔽"，单向 + 无感知是社区通行口径；双向会让被拉黑者通过"突然看不到"推断。
- **拉黑即隐藏历史引用 / 已发通知**：历史通知是既成事实，删除会破坏"通知可回溯"；未读的旧通知保留。
- **管理端查看 / 强制解除**：属运营能力，PRD 未要求；如需要另开 CR。
- **关键词级屏蔽 / 屏蔽版块**：与用户级拉黑不同维度，另开 CR。

## 8. 实施结果（2026-10-23，实施后回填；§1~§7 一字未改）

**与计划一致**：V5 迁移、四个受保护端点、六处读侧过滤（列表 / 搜索 / Feed / 他人主页 / 楼层 / 详情）、互动阻断（关注 / 回帖 / 点赞 / 收藏）、通知抑制、前端主页按钮与设置页黑名单，均按 §3 落地；§7 三条口径按方案默认值执行。

**偏差（如实登记）**：

1. **读侧过滤改为 SQL 侧**（`PostRepository.findPage / search / findPageByAuthors`、`ReplyRepository.findPageByPostId` 新增 `excludedAuthorIds` 参数），而非 §3 原写的"应用层过滤"——应用层剔除会让 `total` 与页内容不同源；SQL 侧使 total 同步（真机实测拉黑前后 total 26 → 25）。代价是 5 个测试文件 32 处调用同步更新。
2. **收藏列表与相似帖仍为应用层剔除**（沿用 CR-048 "页内剔除、total 为收藏行数"的既有取舍；相似帖条数小）。
3. `SimilarPostRow` 新增 `authorId` 字段（Mapper 显式列 + 映射），供相似帖过滤。
4. **公开回帖时间线 `listPublicRepliesByAuthor` 未过滤**（端点无 viewer 参数），登记为已知残余；他人主页的**帖子列表**已过滤。
5. SpotBugs 新增 4 条排除（`BlockedUsers` / `BlockedUsersVo` 的 EI_EXPOSE_REP·REP2，与既有不可变值载体同型）。
6. 测试新增 **14 例**（应用服务 5 / 适配器 3 / 控制器鉴权 5 / 互动阻断 1 / 回帖阻断 1 / 通知抑制 1），基线 537 → **553**。
7. **真机第一次断言脚本有缺陷**：列表 / 搜索请求误带匿名身份、又误用 `items` 字段（实际是 `list`），得出"拉黑前也不可见"的假结果；换账号带令牌重做后通过。如实登记为**验证脚本缺陷、非产品缺陷**。

**验证**：`SPRING_IT=true mvn -o verify` **553 / 0 / Skipped 0** + SpotBugs 0；`npm run lint` / `npm run build` 通过；**真机**双账号：拉黑前列表含对方帖（total 26）→ 拉黑后不含（total 25）、搜索不含、直接访问详情 `404`；对方关注 / 回帖 / 点赞均 `403`；解除后列表恢复、关注与回帖恢复 `200`；黑名单返回「模拟学生39」。**真实浏览器**：`/u/74` 拉黑 → 按钮「已拉黑」且关注禁用；设置页黑名单显示目标 → 解除 → 空态；回主页按钮恢复；控制台仅预期 SSE 中断。**契约 v1.29**（43 路径 / 50 操作 / 77 schema / 37 受保护；+4 操作 / +3 路径 / +5 schema，既有 46 操作与 72 schema 结构化零变化）。
