# CR-201 视觉统一批次 A（首页 / 详情 / 发布）

## 1. 目标

解决「界面太白、层次太平」：让中栏成为唯一视觉焦点，侧栏退为安静的导航区；统一列表密度与字号阶梯；详情与发布页把零散白块收成清晰的阅读 / 编辑工作区。**只做视觉与布局，不加功能、不引依赖、不改接口。**

## 2. 范围

**做**：首页（三栏）、帖子详情、发布 / 编辑页；`tokens.css` 的底色 / 悬停 / 列表标题令牌；`PostListItem` 的密度与层级；这三个页面的响应式（≥1280 / 1024 / 768）。

**不做**：登录 / 个人主页 / 后台等其余页面（批次 B）；不改信息架构与路由；不加插画、渐变、投影、图表库；不改任何接口、数据与鉴权；不调整 `--cl-color-primary` 与 AA 深色令牌。

## 3. 改动点（文件级）

- `frontend/src/styles/tokens.css`
  - `--cl-bg-page` 由 `#f5f6f8` 调至 `#eef1f5`（白卡才有“浮起”感）。
  - 新增 `--cl-bg-subtle: #f7f9fc`（列表 hover / 表头 / 次级分区），替换 `hover:bg-bg-hover` 的蓝色底。
  - 新增 `--cl-font-list-title: 16px`；不改动既有字号阶梯。
- `frontend/src/views/HomeView.vue`
  - 左右栏去掉 `el-card` 外壳，改为透明分组：12px 分组标签 + 列表项，组间用 0.5px 分隔线；中栏保留唯一白卡。
  - 删除排序条与右栏卡头的 `primary-soft` 底色带，改白底 + 底部细线；选中 Tab 仍为主色文字 + 2px 下划线。
  - 右栏「等你来答 / 全站热榜」改为无卡分区，行距收紧，更多链接降为 12px。
- `frontend/src/components/PostListItem.vue`
  - 删除行级版块色条（`cl-board-rail-*` 不再使用）；版块色只保留元信息行的 6px 色点。
  - 标题改用 `--cl-font-list-title` + 600 字重；摘要 13px / 1.65；元信息 12px。
  - 行内边距 `py-4` → `py-3.5`，hover 改 `--cl-bg-subtle`。
- `frontend/src/views/PostDetailView.vue`
  - 右侧目录包成 240px 的 sticky 小卡（白底、0.5px 边框、12px 内边距），无标题时维持现有居中逻辑。
  - 操作条（点赞 / 收藏 / 编辑 / 删除）改浅底分组，主操作实心、次操作描边。
  - 回复空态改为图标 + 文案 + 主色按钮；回复区与正文卡间距统一 16px。
- `frontend/src/views/PublishView.vue`
  - 顶部版块 / 标签 / 发布按钮与正文编辑器收进一张卡；标题输入 20px、聚焦时下划线提亮。
  - 编辑区最小高度 520px，预览区同高；底部“预览与发布一致”说明降为 12px。
- `docs/设计/UI规范/界面规范.md`：新增本节视觉约定（报告交付时同步）。

## 4. 步骤

1. 先改 `tokens.css` 三个令牌 + `PostListItem`，首页截图确认列表密度与 hover。
2. 改 `HomeView` 三栏层次（侧栏去卡、中栏唯一白卡、卡头去色带）。
3. 改详情页目录卡与操作条、空态。
4. 改发布页工作区并统一间距。
5. 三页在 1440 / 1024 / 768 逐页截图，修溢出与断点问题。
6. 同步界面规范，跑一致性脚本与前端三项检查。
