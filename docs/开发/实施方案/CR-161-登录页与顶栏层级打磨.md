## 0. 设计参数（从项目规范推导，不另设）

`ui-craft` 要求的四个旋钮按界面规范取值：**模式 Operate + Read**、CRAFT 8（已有严格规范）、MOTION 3（装饰为零，仅 hover / 微交互）、DENSITY 8（论坛信息密度优先）、VARIANCE 3（对称克制）。**不换主色、不加阴影 / 插画 / 常驻装饰**。

## 1. 目标

修掉三处「模板感 / 层级不清」，并把一处既有渐变偏差拉回规范：

- 登录页左卡不再重复标题文案（「标题 + 三个卖点条目」是典型模板结构）；
- 顶栏匿名态只保留**一个**主色 CTA（现有「提问」与「登录 / 注册」两个实心主色按钮竞争注意力）；
- 详情页操作行（点赞 / 收藏 / 举报）视觉权重统一；
- 列表项 hover 增加一个克制的主色 signature detail（不位移）。

量化口径：登录页左卡与标题重复的文案 **0 处**；顶栏匿名态主色实心按钮 **1 个**；详情页三个操作同一字号 / 间距 / 层级；列表 hover 指示条仅 hover 出现、不影响布局。

## 2. 范围

- **做**：
  - `LoginView` 左卡：删除与 `h2` 重复的 `values` 三条（问有所答 / 学有同伴 / 求职有路），改为三条**事实**（仅限本校 · 学籍核验注册 · 6 个固定版块）；背景由 `cl-hero-bg` 渐变改为**纯色浅底**（对齐「渐变仅首页 hero 一处」）；
  - `App.vue` 顶栏：匿名态「登录 / 注册」由主色实心改**描边按钮**，让「提问」成为唯一主色 CTA；
  - `PostDetailView` 操作行：点赞 / 收藏统一为「图标 + 文字」按钮、选中态统一用**主色**（收藏不再用 `warning` 橙）、计数 `tabular-nums`；举报保持右侧 `link` 次操作（次要 / 危险操作不与点赞同权重，避免操作行出现三个同级按钮）；
  - `PostListItem`：行 hover 时左侧出现 **2px 主色指示条**（`::before`，不位移、不改变布局边界）；
  - `界面规范 §2` 加注：登录页品牌区去渐变，收敛为「渐变仅首页 hero」。
- **不做**：
  - 不换主色 / 字体 / UI 框架，不加阴影 / 插画 / 常驻装饰；
  - 不改详情页楼层号（已为灰底 `bg-code`，与「楼主」蓝标签语义已区分）；
  - 不改接口契约 / 后端 / 布局框架（三栏 CR-100）；
  - 台账 / 驾驶舱本轮不碰（并发 CR-159 文档改动未提交，待其提交后补登记）。
