## 1. 目标

Sprint 4 治理批次的**后端一支**：发帖/回帖接入内容机审网关（fail-closed）、举报提交与工单闭环、用户封禁、账号注销（7 天冷静期 + 匿名化定时任务）。

## 2. 范围（做与不做）

**做**：① `ModerationGateway` 端口（forum.domain）+ `LogModerationGateway`（log 模式：决策留痕、默认放行；**fail-closed**：实现内部异常 → 5002 拦发布）接入发帖/回帖；② `POST /api/v1/reports`（需登录，24h 同对象去重，reports 表 V1 已建）+ admin 工单两支（分页 / 处理：联动 CR-066 下架或驳回，闭环 + 审计）；③ `PUT /api/v1/admin/users/{id}/status`（ACTIVE/BANNED，requireRole SUPERADMIN = G9；发帖回帖前校验作者未被封禁）；④ 注销：`POST /api/v1/users/me/deactivate`（status=DEACTIVATED + delete_at=+7d）+ **冷静期内登录即撤销**（恢复 ACTIVE + 审计）+ 期满拒绝（新码 2010）+ **匿名化定时任务**（每小时：置 anonymized、清 email/phone/student、昵称置「已注销用户」、审计）；⑤ 全部处置/治理动作写审计。
**不做（如实登记）**：真实机审服务商适配（需发起人选型与 API 凭据，next-steps P3；本轮端口 + log 通道 + 降级语义即工程可交付部分）；禁言的定时解锁（MVP 只做封禁 BANNED，禁言列 P1）；举报的前端入口与 /admin 后台页（归下一批 CR-083）；关注类通知。

## 3. 改动点（文件级）

- forum：`ModerationGateway`/`ModerationVerdict`（domain）+ `LogModerationGateway`（infrastructure）+ Post/Reply 用例前置机审 + `Report` 实体 / mapper / 仓储 / `ReportApplicationService`（submit/adminPage/close，close 联动 `updateStatus`）+ `ReportController` / `AdminReportController`；新码 `2010 ACCOUNT_EXPIRED(403)`。
- account：`AdminUserController`（封禁，requireRole）+ `deactivate` 用例（含审计）+ 登录撤销 / 期满拒绝分支 + `UserAnonymizationScheduler`（account.infrastructure.scheduling，@Scheduled + 审计）+ 封禁后发帖/回帖前置校验（经 AccountApplicationService 暴露 `assertNotBanned`）。
- **契约**：新增 6 端点（reports 1 / admin 3 / deactivate 1）+ 2009/2010 行——快照再生成随下一契约轮（并发会话 v1.15 模式），本 CR 内先落代码与单测。
- 前端：不在本 CR（归 CR-083）。

## 4. 步骤 → 5. 验证

实体/端口/用例/控制器 + 单测（举报去重与枚举 1001、封禁后登录 403/2006 与发帖 403、机审 fail-closed 5002、注销冷静期登录撤销、期满 2010、匿名化字段清空 + 审计）→ `mvn verify` 全绿（298 → 310±）→ 真机冒烟（举报去重 / 工单闭环 / 封禁 / 注销全链路）→ 台账 / 驾驶舱回置。

## 6. 回滚

本 CR 零迁移（reports 表 V1 已建）；代码 revert 即回滚；匿名化任务不可逆操作仅对「冷静期满且未撤销」账号执行，revert 后无残留写路径。
