## 1. 目标

兑现发起人 2026-09-19 拍板「**届徽章现在就上，Q1（学号编码规则）核实后据实调整**」：他人主页资料卡展示入学年级徽章。概念图轮已定「身份卡只展示届、不需要 24 级」，主 PRD 亦有注「`grade` 由学号届别推导（当前未展示）」。

现状取证（2026-10-26）：
- `users.grade` **全库 0 行非空**（注册链路经 `StudentRecord.grade` 却从未落库）；
- `student_roster.grade` 格式**不统一**：开发库 45 行「模拟2024级」、3 行「2023」、5 行 NULL——真实名册格式本就以 **B2 决策为准**（V1 注释明示），**不能依赖固定格式**；
- 学号**不落明文**（只存 HMAC 哈希与加密串），「学号前两位推导」无数据可用——且该路径正是 R-6 否决的循环取证项；
- 注销匿名化已清 `users.grade`（CR-127 起 13 列之一），展示随之为空，无需额外处理。

## 2. 范围

**做**：

- **注册时快照**：`register` 占用名册时（`rosterGateway.occupy`）顺带同事务回读 `student_roster.grade`，**归一化**（提取首个 4 位数字年份，如「模拟2024级」→`"2024"`、「2023」→`"2023"`；提不出则不快照，存 null）后经 `Account.registered` 工厂写入 `users.grade`；bypass 模式（开发）与名册无 grade 时为 null；
- **出参**：`PublicProfile` 与 `UserProfileVo` 各加可空字段 `grade`（string，4 位年份数字或 null；null 不渲染徽章）；契约快照再生成（既有 schema +1 属性）；
- **历史账号回填**：新增 `backend/scripts/data/D003__backfill_grade_from_roster.py`——按 `student_roster.used_user_id = users.id` 关联回填（同一归一规则，幂等：`grade IS NULL` 才写）；
- **前端**：`ProfileView` 资料卡昵称旁年级徽章胶囊（复用既有徽章样式，`grade` 为 null 不渲染）；
- **文档口径**：`PublishPostCommand` 侧无关；`ProfileField`/`UserProfileVo` 中「grade 不下发 / 不开放」的既有注释与增量 PRD 三分表口径同步改写（grade 变为**注册快照只读**字段，仍无用户编辑入口——E-012 的「school 不给填」定性不变）。

**不做**：

- 不做「届」换算（入学年 +4 = 毕业年）——数据语义就是入学年级，文案口径见 §7 D1；
- 不做方向标签 / 状态标签 / 行为徽章（F-ACC-005 其余项维持评审不通过结论）；
- 不做 grade 编辑入口（名册快照只读；`PUT /users/me` 三字段不动）；
- 不做读时联名册（快照解耦：名册后续变更不回写老账号，匿名化后自然消失）；
- 零迁移（`users.grade` 列 V1 已有）。

## 8. 实施结果（2026-10-26）

**原计划 vs 实际**：按 §2 / §3 / §7 默认口径（D1 文案「{N} 级」不换算）落地，零迁移、零新错误码。**一处实现路径偏差（更省侵入）**：原计划改 `RosterGateway.occupy` 签名带回 grade，实施改为 register 内 save 前用**既有 `findAvailableByHash`** 读名册行快照（此刻行尚未占用、必为 available）——端口与两个策略实现零改动，`occupy` 保持 boolean。

**实际改动**：

- 新增 `account/domain/model/CohortYear`（`normalize`：提取首个 4 位年份，提不出 null）；
- `Account.registered` 新增带 grade 的四参重载（原重载转发、语义不变）；`AccountApplicationService.register` 建号前快照（查不到名册行为 null，不影响注册成败）；
- `PublicProfile` / `UserProfileVo` 各 +可空 `grade`，`UserProfileVo` 注释从「grade 不下发」改写为快照口径（`school` / `avatarUrl` 仍不下发）；
- 新增 `backend/scripts/data/D003__backfill_grade_from_roster.py`（归一规则与后端同源、幂等 `grade IS NULL` 才写、dry-run 默认）；前端 `api/user.ts` +`grade` 类型、`ProfileView` 资料卡「{N} 级」胶囊（null 不渲染）。

**验证**：

- `SPRING_IT=true mvn -o verify` **737 / 0 failures / Skipped 0** + SpotBugs 0 + 覆盖率门禁过（733 → 737，+4：`CohortYearTest` 3 + register 快照 1；首轮唯一失败正是快照探针拦「`UserProfileVo.properties.grade` 归档缺字段」，重抓后全绿）；`npm run lint` exit 0、`build` ✓；
