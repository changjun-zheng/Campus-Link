# CR-202 视觉统一批次 B（列表页页头统一）

| 文档信息 | 内容 |
|---|---|
| 版本 | v1.0 |
| 状态 | 已实施（结果见 §7） |
| 维护人 | 前端（发起人兼任） |
| 最后更新 | 2026-11-06 |

## 1. 目标

批次 A 把首页 / 详情 / 发布改成「页面底色 + 唯一白卡」，但其余列表页仍是「标题一张小卡 + 内容一张卡」——上下两块白卡把页面切成两条，和批次 A 的层次相反。本批把这套规则推到 9 个内容页：**页头透明、内容卡唯一**，并抽一个共用页头组件避免九处各写一遍。

## 2. 范围

**做**：我的收藏 / 我的帖子 / 我的回帖 / 通知中心 / 粉丝关注列表 / 组队广场 / 版块页 / 搜索页 / 私信列表，共 9 页的页头与筛选条；新增 `components/PageHeader.vue`。

**不做**：登录 / 注册、个人主页、设置、管理后台、组队详情与发布、私信会话页、帖子详情（已由批次 A 覆盖）。不改任何接口、数据、鉴权、路由与字号令牌。

## 3. 改动点（文件级）

- **新增** `frontend/src/components/PageHeader.vue`：透明页头——`h1` 20px / 600（`--cl-font-title-lg`）、可选说明 13px `--cl-text-meta`、右侧 `actions` 插槽、底部 `default` 插槽放 Tab / 筛选条，整块以 0.5px `--cl-border-base` 收底；无卡片、无阴影。props：`title`、`description?`。
- `MyFavoritesView.vue` / `MyPostsView.vue` / `MyRepliesView.vue` / `MessagesView.vue`：删掉标题 `el-card`，换 `PageHeader`；内容卡保留。
- `NotificationsView.vue`：`PageHeader` + `actions` 插槽放「全部 / 未读」筛选与「全部已读」。
- `FollowListView.vue`：`PageHeader` 标题内保留昵称链接，Tab 走默认插槽。
- `TeamsView.vue`：标题卡改 `PageHeader`（右侧「我的组队 / 发起组队」），**筛选条卡一并去掉**——方向下拉与状态 Tab 直接排在页头下，与内容卡留 16px。
- `BoardView.vue`：面包屑下改 `PageHeader`——版块图标（沿用 `cl-board-icon`）+ 版块名 + 描述 + 右侧「发帖」；「待解答」Tab 走默认插槽。
- `SearchView.vue`：标题 + 说明 + 搜索表单移出白卡（输入框自带白底与描边），结果卡保留。
- `docs/设计/UI规范/界面规范.md`：新增批次 B 约定（交付时同步）。

## 4. 步骤

1. 写 `PageHeader.vue`，先在一页（我的收藏）落地并截图确认。
2. 按「纯标题」→「带动作」→「带 Tab / 筛选」的顺序替换其余 8 页。
3. 修页头与内容卡之间、页头内部的间距（统一 16px / 12px 两档）。
4. 三档视口逐页截图，修溢出与折行。
5. 同步界面规范，跑一致性脚本与前端三项检查。

纯前端模板与样式，无接口 / 数据 / 迁移；整笔 revert 本 CR 提交即恢复原样。个人主页与设置等页面维持现状，不随本批变化。

## 7. 实施结果（实施后追加，不回改上文）

- **交付**：`components/PageHeader.vue` + 9 页页头替换全部落地；筛选条 / Tab 由独立卡片并入页头，内容区收成单张白卡。`PageHeader` 四段插槽：`lead`（版块图标）/ `title`（粉丝页昵称链接）/ `actions` / 默认插槽（Tab、筛选条、搜索表单）。
- **偏差（原计划 vs 实际）**：① 计划「先在一页落地再批量替换」没有单独留一步，九页一次性改完、逐页截图比对；② 发现并修复一类原计划未预见的缺陷——`el-select` 用 Tailwind `w-*` 会被 EP 无层样式压掉（搜索页两个下拉塌成箭头宽、组队方向下拉撑满整行），改在 scoped 样式里写 `--el-select-width` + `width` + `flex: none`；③ 粉丝 / 关注页标题里的昵称链接被全局 `a` 无层规则染成链接蓝，组件内用类选择器拉回墨色、hover 才现链接色。
- **验证**：`npm run typecheck` / `lint` / `build` 全 exit 0；Playwright 1440×1000 / 1024×900 / 768×900 三档 × 9 页共 27 张截图，**无横向溢出、无 console error**；交互实测——通知「未读」发出 `?unread=true` 并显示「没有未读通知」、组队「已满员」Tab `aria-pressed=true` 且空态正确、版块「待解答」URL 带 `filter=unanswered`、搜索提交写回 `keyword` 并渲染结果数；页头标题实测 `rgb(48,49,51)`、hover `rgb(26,111,196)`；`check_docs_consistency.py` exit 0。
- **未测**：真实触控设备与窄屏断点矩阵（仍是 W-03 补偿③ 范围）；登录 / 注册、个人主页、设置、后台、组队详情与私信会话页留后续批次。
