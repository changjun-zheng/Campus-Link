## 1. 目标

补 PRD P1「人工巡查队列」的最小可验收形态：给 SUPERADMIN 一个**按发布时间倒序的最近内容列表**（帖子 / 楼层切换），可直接就地 **下架 / 恢复**（复用既有处置端点），把「先知道 ID 才能处置」的现状补上「发现入口」。

## 2. 范围

- **做**：
  - 受保护端点（仅 SUPERADMIN）`GET /api/v1/admin/review-queue?kind=post|reply&page=&size=`：
    条目 `id / kind / title / boardName / authorNickname / status / createdAt`；
    `kind` 只认 `reply`，其余（含空 / 非法）一律按 `post`；`title` 帖子取标题、楼层取正文纯文本前 60 字（**不含 HTML**）；
    按 `created_at DESC, id DESC`；**只列 `is_deleted = 0`**（作者自删不出现），**已下架（REMOVED）仍列出**（便于恢复）；
    `page` / `size` 归一（`page ≥ 1`、`1 ≤ size ≤ 100`），`total` 与页内容同 WHERE。
  - 两条 `@Select`（帖子 / 楼层各一条，JOIN `users` / `boards`，楼层经 `posts` 取版块），**不做字符串拼接、不引入 UNION**。
  - 前端：`AdminView` 第五 Tab「内容巡查」——类型切换（帖子 / 楼层）、列表（标题 / 版块 / 作者 / 状态 / 时间）、分页；
    每行「下架 / 恢复」按钮，确认后调**既有** `PUT /admin/posts/{id}/status` 或 `PUT /admin/replies/{id}/status`，成功后刷新当前页。
  - 契约快照重抓（预期 +1 操作 / +1 路径 / +3 schema / 新 tag `admin-review`），契约 README / 技术方案 §5 / 界面规范 / 台账 / 驾驶舱回置。
- **不做**：
  - 风险抽样 / 打分模型（PRD 无详设，本轮只做「最近内容」时间序）；
  - 关键字筛选、按状态筛选、批量处置、处置记录页签（处置审计沿用既有 `MODERATE_POST` / `MODERATE_REPLY`）；
  - **已被作者删除内容的恢复**（`is_deleted = 1` 不进队列，恢复删除不在任何 PRD 条目内）；
  - 巡查结果标记（「已看过 / 已忽略」）——无对应数据表，且 PRD 未定义。

## 8. 实施结果（实施后追加，不回改上文）

- **与计划一致**：`GET /api/v1/admin/review-queue`（`requireRole(SUPERADMIN)`）、`ReviewQueueGateway` + 两条 `@Select` + 两条 `COUNT` + `ReviewQueueGatewayImpl` / `ReviewQueueApplicationService` / `ReviewQueueController` / `ReviewQueueVo`、前端 `api/admin.ts` + `AdminView` 第五 Tab，均按 §3 落地；§7 四条口径按默认值执行。
- **偏差 1（楼层多一条过滤，已写入契约 README §3.11）**：§2 只写「只列未删内容」；实现时把 **父帖已被作者删除的楼层** 一并排除（`JOIN posts p … AND p.is_deleted = 0`，`COUNT` 同 WHERE）——父帖不可访问时楼层处置无意义。真机验证：父帖删除后楼层 `total 29 → 28`。
- **偏差 2（静态扫描）**：SpotBugs 首跑 4 条（`ReviewQueueApplicationService$ReviewQueue` 与 `ReviewQueueVo` 的 `items` List 字段 `EI_EXPOSE_REP` / `REP2`），按既有 ③ 组惯例加入 `spotbugs-exclude.xml`，复跑 0。
- **验证实测**：`SPRING_IT=true mvn -o verify` **587 → 596**（0 failures / Skipped 0，+9 例 / 3 个测试类）；`npm run lint` exit 0、`npm run build` 通过；契约 **v1.33**（49 路径 / 56 操作 / 88 schema / 17 tag / 43 受保护、166694 字节、+173 / −0 纯新增，`operationId` = `reviewQueue`，无撞车）。
- **真机取证（真实后端 + 真实库）**：dev-stu-09 发帖 + 回帖 → `kind=post` 首条即新帖（标题 / 版块「技术问答」/ 作者昵称 / `PUBLISHED`）、`kind=reply` 首条为**正文纯文本摘要**（无 HTML 标签）→ `kind=xxx` 归一 `post`、`page=0&size=999 → 1/100` → 下架帖子后队列该行 `status=REMOVED`、恢复回 `PUBLISHED`，楼层同法 → 匿名 `401`、普通用户 `403` → **父帖删除后楼层 total 29 → 28**（父帖剔除生效）；`audit_logs` 有 `POST_REMOVE / POST_RESTORE / REPLY_REMOVE / REPLY_RESTORE` 各 1 条（`reason=巡查队列验证`），处置端点复用正确。
