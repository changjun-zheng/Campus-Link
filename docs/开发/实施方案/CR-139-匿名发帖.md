## 1. 目标

让登录用户发帖时可选择**匿名发布**：公开面（列表 / 搜索 / 详情 / 收藏 / 关注 Feed）只显示「匿名用户」，不暴露作者 id 与主页链接；真实作者仍保留在 `posts.author_id`，用于通知、审计、管理处置、编辑 / 删除与「我的帖子」。零改既有数据、零新建内容形态。

## 2. 范围

**做**

- 新增迁移 `V9__post_anonymous.sql`：`posts.is_anonymous TINYINT(1) NOT NULL DEFAULT 0`；
- `Post` 聚合增 `anonymous`，发帖入参 `PublishPostCommand.anonymous`；编辑不可切换匿名标记；
- 公开出参掩名：`PostSummary` / `PostDetail` / 搜索 / 收藏 / 列表统一 `authorNickname = "匿名用户"`；`PostDetail.authorId` 改可空，**仅作者本人请求时回填**（采纳 / 编辑 / 关注判定要用）；
- 隐私隔离：匿名帖不进他人主页帖子时间线与关注 Feed、不计入公开帖子数 / 获赞数 / 声望；「我的帖子」仍列出并带匿名标记；
- 拉黑语义：匿名帖**不参与拉黑过滤与互动阻断**（否则「看不到 / 回不了某人的匿名帖」就是身份侧信道）；
- 前端：发布页「匿名发布」复选（默认否、发布后不可更改）、列表 / 详情 / 我的帖子匿名标记、详情隐藏作者主页链接与关注 / 私信按钮；
- 契约重抓（`PostSummaryVo` / `PostDetailVo` / `MyPostSummaryVo` / `EditablePostVo` 加 `anonymous`，`PostDetailVo.authorId` 变可空）。

**不做**

- 匿名回帖 / 匿名评论 / 匿名组队 / 匿名私信（只做发帖）；
- 匿名帖的「随机分身昵称 / 头像」（统一显示「匿名用户」，不做身份混淆池）；
- 发帖后切换匿名状态、匿名帖认可 / 勋章 / 排行榜展示；
- 对管理员隐藏真实作者（运营处置与审计必须知道作者）；
- 反作弊 / 匿名帖频率限制（沿用发帖既有权限与限流）。

**偏差与说明**：① `PostDetailVo.authorId` 改为可空 `Long` 后，**OpenAPI 快照上看不出可空性**（springdoc 仍输出 `type: integer`、无 required 差异），已在契约 README 登记为表达极限；② 原计划写「`PostDetailVo` 等 4 个出参」，实际入参 `PublishPostCommand` 也需带 `anonymous`，共 5 个 schema；③ 详情页「楼主」徽标曾只按 `authorId` 比对，匿名帖若对非作者返回 null 会失去徽标/反推作者，已补 `authorId !== null` 前置判断；④ 验收未新建第二个匿名帖做浏览器发布动作（API 已完整验证发布链路），浏览器只读既有验收帖与页面，避免遗留数据；⑤ 测后已清理验收帖、楼层、点赞、收藏、通知与标签关联（`posts` / `replies` / `favorites` / `post_tags` 相关行 0）。
