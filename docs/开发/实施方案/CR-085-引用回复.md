# CR-085 实施方案：引用回复（F-009，登记与实施同批）

| 文档信息 | 内容 |
|---|---|
| 关联 | 问题清单 F-009 · PRD F-FORUM-004 / F-SOC-001 · V1 迁移 `replies.quoted_reply_id`（第 120 行，预留零使用） |
| 评审方式 | 发起人指令"继续完善功能" + 授权自审代批 |
| 状态 | 实施完成（2026-09-27） |

## 1. 目标

打通"引用回复"场景：回帖时可引用**同帖**的某一楼层，楼层列表就地渲染引用摘要（楼层号 + 昵称 + 120 字纯文本摘要），被引用者收到 `quote` 类型通知并可跳转到引用方楼层。`quoted_reply_id` 列与 `NotificationType` 词表（V1 DDL 注释 `reply/like/favorite/accept/quote`）均已预留，本轮补上**唯一写入口**与读侧组装，**零迁移**。

## 2. 范围

**做**：楼层「引用」按钮 → composer 引用条 → 提交带 `quotedReplyId`；后端校验（可见 + 同帖）→ 落库；楼层列表出参加 `quoted`；`NotificationType.QUOTE` + `replyQuoted` 触发入口；通知中心动作短语与页头副标题。

**不做**：跨帖引用（3001 拒绝，同 BUG-001 防枚举口径）；引用帖子本体（只支持楼层）；"我的回帖"展示被引用信息；通知实时推送（F-010 残余另案）；引用块点击跳被引楼层（受"最佳答案置顶改分页组成"影响，沿用 focusFloorFromQuery 的不猜页码判据，另批）；发帖页引用（帖子本体占位不同，另批）。

## 3. 改动点（文件级）

**后端**：`PublishReplyCommand`（+`@Positive Long quotedReplyId` 可空）；`Reply`（聚合 +quotedReplyId，`post()` / `rehydrate()` 各 +1 参）；`QuotedReplyNotFoundException`（新，3001/404）；`ReplyApplicationService.reply`（引用校验**先于机审**——让 3001 准确于 5002，同既有"帖子可见性先于机审"注释的口径；传参 + `replyQuoted` 通知）；`ReplyRepository` / `ReplyRepositoryImpl`（+`findVisibleByIds`：`in` + `status='PUBLISHED'` + `is_deleted=0`，与 `findVisibleById` 同源）；`ReplyConverter`（双向接线）；`ForumResults`（`ReplyItem` +quoted、+`QuotedBrief(replyId, floorNo, authorNickname, excerpt)`）；`ForumQueryApplicationService.listReplies`（批量组装引用摘要，昵称**并入同一批** `nicknamesOf`，excerpt 走 `toPlainSummary` 120 字；被引楼层不可见 → `quoted=null` 不渲染——"内容不可见不外泄"口径）；`ReplyVo`（+nested `QuotedReplyVo`）；`NotificationType`（+`QUOTE("quote")`）；`NotificationApplicationService`（+`replyQuoted`，自引用抑制沿用 `notify()` 既有兜底）。

**前端**：`api/forum.ts`（`ReplyVo.quoted?` + `publishReply` 第三参）；`PostDetailView.vue`（引用按钮 / quoting 状态 / composer 引用条可取消 / 楼层引用块，样式只用令牌与既有工具类）；`NotificationsView.vue`（`actionOf` +quote 分支）。

## 4. 步骤

后端 11 文件 → 单测补充 → `mvn verify` 全绿 → 前端 3 文件 → `npm run build` → 起栈真机冒烟 → 重抓 `openapi.json`（**同轮闭环 CR-082/083 的契约挂账**：新端点 + 2011~2013 码 + tags 字段一并入快照）→ 台账 / 问题清单 F-009 加注 / 契约 README / 驾驶舱。

## 5. 验证

`mvn verify` 全绿（基线 346 → 356）；`npm run build` 通过；真机冒烟：A 发帖 → B 引用回帖 → 楼层列表出 `quoted` 且 A 收 `quote` 通知（跳 `?floor=` 命中引用方楼层）；引用不存在 id → `404/3001`；引用它帖楼层 → `404/3001`；匿名回帖仍 `401/4001`；契约 diff 逐行归因（预期仅 quoted 三处 + CR-082/083 补齐）。

## 6. 回滚

纯前向改动、零迁移，`git revert` 单提交即可。⚠️ 唯一数据面：若回滚代码而库中已产生 `type='quote'` 通知行，通知读侧 `fromCode` 会抛错——回滚须先清理该类型行（dev 库一条 DELETE）。
