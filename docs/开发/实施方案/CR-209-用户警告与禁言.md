## 1. 目标

补齐 PRD F-ADMIN-002「对用户警告 / 禁言 / 封禁」中缺失的**警告**与**禁言**：管理员可向目标用户发送带原因的警告，或临时禁言；禁言期间发帖 / 回帖 / 上传图片 / 发起组队等写操作统一拒绝；警告与禁言均写审计并给用户站内通知。

## 2. 范围

- **做**：V13 迁移新增 `users.muted_until`、`notifications.message`；新增 `POST /admin/users/{id}/warn`、`PUT /admin/users/{id}/mute`、`DELETE /admin/users/{id}/mute`；写守卫拆为 `assertAllowedToWriteContent`（状态 + 禁言），覆盖帖子 / 回复 / 图片 / 组队写入口，**读取与登录不受影响**；新增通知类型 `warning` / `mute` 与目标类型 `USER`；管理后台操作区与通知中心渲染。
- **不做**：不做警告历史列表 / 撤销警告；不做永久禁言（永久处置用封禁）；不做 OPS 降级；不改封禁 / 注销语义；本轮不覆盖私信发送；不做定时解禁任务（读取时按截止时间判定，过期即自然失效）。

## 实施结果（2026-11-08）

- **实际 vs 计划**：计划写「禁言校验挂 `assertActiveForContent`」，实施时拆为 `assertAllowedToWriteContent`（状态 + 禁言），原方法保留给读取路径——否则禁言用户连自己的草稿图片都读不了；写入口 6 个（帖子发布 / 编辑、回复、图片、组队发起 / 申请）全部切换，读取与登录不受影响。
