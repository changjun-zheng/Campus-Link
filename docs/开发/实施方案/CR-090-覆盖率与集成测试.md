## 1. 目标

把提测准入门"7 项中 4 项未满足"里的**两项工程前置**在本地做掉：覆盖率**可测**（E-002）与**最小集成测试**（E-001）——Flyway / Mapper 扫描 / `SecurityFilterChain` / MySQL + Redis 真实连接此前只有真机人肉验证兜底。**CI 静态扫描（E-003）涉 CI/CD 配置红线，本轮只产出 YAML 备料，待发起人批准后另行落地。**

## 2. 范围

**做**：① `pom.xml` 接入 jacoco-maven-plugin 0.8.12（prepare-agent + report，`target/site/jacoco/`）；② `UserAnonymizationScheduler` 加 `@ConditionalOnProperty(campuslink.account.anonymization.enabled, matchIfMissing = true)` 装配开关（**既有行为零变化**，给集成测试一个关闭口）；③ 新增 `integration/SpringBootContextTest`：`@SpringBootTest(MOCK)` + `@AutoConfigureMockMvc`，类级 `@EnabledIfEnvironmentVariable(named = "SPRING_IT", matches = "true")`——**默认 mvn verify 跳过（CI 无服务不破），本机真机跑通**；④ CI YAML 备料（本文 §5，不落地）。

**不做**：CI workflow 改动（红线，待批）；Testcontainers（新重依赖，等 CI 决策一起定）；jacoco check 强制阈值——**先实测再定**：实测 ≥ 60% 即按提测门标准开闸，不足则登记缺口、check 规则挂账（不开假门槛）；静态扫描、Code Review 归档（E-004，另行批次）。

## 3. 改动点（文件级）

- `backend/pom.xml`：+jacoco 插件两执行（prepare-agent / report）
- `module/account/infrastructure/scheduling/UserAnonymizationScheduler.java`：+`@ConditionalOnProperty`（matchIfMissing=true）
- `src/test/java/com/campuslink/integration/SpringBootContextTest.java`（新）：4 例——① `@SpringBootTest` 上下文加载（隐含 Bean 装配 / `@MapperScan` / `SecurityFilterChain` 构造）；② JdbcTemplate 查 `flyway_schema_history` 全部 `success=1`；③ 匿名 `GET /api/v1/boards` → 200 且版块 ≥ 6（公开读 + Mapper + 真库）；④ 匿名 `POST /api/v1/posts` → 401 且 `code=4001`（**过滤器链 fail-closed 首次进测试**，此前只有真机取证）。测试属性：热榜初延迟/周期推至 1h、匿名化开关 false——**调度器副作用出测试生命周期**。

## 4. 步骤与验证

pom → 调度器开关 → 测试类 → `mvn -o verify` 全绿（4 例默认 SKIPPED）→ `SPRING_IT=true mvn -o verify`（本机 MySQL/Redis 真机）4/4 通过 → jacoco 报告实测覆盖率回填本节 → `openapi.json` 零 diff（无 Controller / VO / 校验注解改动）→ 台账 / 问题清单 E-001、E-002 加注。

## 5. CI 备料（红线待批，不落地）

`backend-ci.yml` 拟增：`services: mysql:8（health check）+ redis:7`、步骤 `SPRING_IT=true mvn verify`（集成测试自此在 CI 真实跑）+ 可选 jacoco 上传；静态扫描（SpotBugs/PMD/依赖漏洞）另议选型。**批准后另开小 CR 落地。**

## 6. 回滚

revert 单提交即可；`@ConditionalOnProperty` 为纯新增装配条件（matchIfMissing=true），回滚无数据面。

## 实施结果

- 单测 354 → **358**（+4 例集成测试）：默认 `mvn verify` **358 全绿 / 4 例 SKIPPED**；`SPRING_IT=true` 真机 **358/358 全绿、集成 4/4 通过**（上下文 9.5s 启动，热榜/匿名化调度器零副作用）。⚠️ **一处 Boot 4 实测差异**：`@AutoConfigureMockMvc` 已随 Boot 4 测试模块拆分迁至 `spring-boot-webmvc-test`（新 test 依赖，包路径 `org.springframework.boot.webmvc.test.autoconfigure`）——按 Boot 3 惯写的 `org.springframework.boot.test.autoconfigure.web.servlet` 编译即错。
- **jacoco 0.8.12 接入并开闸**：实测行覆盖 **66.4%**（1360/2047；真机与默认两口径完全一致——集成测试覆盖的路径与既有单测重合）≥ 提测门 60%，`check` 规则（BUNDLE / LINE / 0.60）随 verify 强制；**反证成立**（阈值临时抬 0.99 → `Rule violated ... 0.66` + BUILD FAILURE，复原后全绿）。**核心模块 ≥80% 暂不开规则**：module 聚合实测 **61.9%**，缺口如实登记于问题清单 E-002，达标后另开 CR 加规则，不开假门槛。报告：`backend/target/site/jacoco/`。
- `UserAnonymizationScheduler` 加装配开关（`campuslink.account.anonymization.enabled`，matchIfMissing=true 零行为变化）+ 热榜初延迟/周期在测试属性内推至 1h——调度副作用出测试生命周期。
- 零 Controller / VO / 校验注解改动 ⇒ 契约快照零 diff（无需重抓）。
- CI YAML 备料见 §5（services mysql/redis + `SPRING_IT=true`），**CI 配置属红线待发起人批准**，批准后另开小 CR 落地。
