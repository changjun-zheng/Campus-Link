# CR-158 · 首页与列表视觉识别度优化

| 文档信息 | 内容 |
|---------|------|
| 版本 | v1.0 |
| 状态 | 待确认 |

## 1. 目标

消除「全站一个蓝」的模板感：让 6 个版块在首页与列表中一眼可区分，并拉出列表项与右栏的视觉层次。**不动布局框架、不加装饰**。

量化口径（验收照此判）：

- 首页左栏 6 个版块图标容器颜色互不相同（现状：6 个全为主色浅底）；
- `showBoard=true` 的列表项出现版块色点（首页 / 搜索 / 收藏 / 个人主页；版块页不显示）；
- 首屏可见帖子条数不下降（现状 6 条）；
- Lighthouse 可访问性保持 100，主色白字对比度不回退（5.10:1）。

## 2. 范围

- **做**：
  - 首页左栏版块导航接入**既有**版块识别色（复用 `.cl-board-icon--{code}`，新增 28px 尺寸档）；
  - `PostListItem` 元信息行的版块入口前加 6px 色点（**新增规范例外，见 §3 注**）；
  - 首页右栏三卡层次化：热榜行高收紧、三卡标题统一、最新发布元信息降档；
  - 版块页「全部 / 待解答」由 EP radio-button 改为与首页排序条同构的文字 Tab；
  - 列表项摘要色降一档（`ink-regular` → `ink-meta`），标题更突出；
  - 按需补 Tabler 图标（如 `flame`），名册同步；不新增后端字段。
- **不做**：
  - 不改三栏布局框架（CR-100）、不增减右栏卡片、不改圆角 / 阴影体系；
  - 不换主色（保持 `#409eff`，CR-024 已定）、不换字体 / UI 框架，不引入插画、渐变、投影、大圆角；
  - 不改接口契约与后端；不加置顶 / 精华（`PostSummaryVo` 无此字段）；
  - 不改头像 8 色令牌与 FNV 哈希（跨会话稳定是约定）；
  - 不改 Markdown 渲染链路与安全相关代码。
