## 1. 目标

消除细节层面的「不专业 / AI 味」：图标尺寸散值过多、可点元素缺 pressed 反馈、不支持 reduced-motion；并如实更正 CR-158 ⑤ 的无效降档。**不动布局、不换色、不加装饰**。

量化口径（验收照此判）：

- `SvgIcon` 尺寸从 **16 种散值**（12/13/14/15/16/18/20/22/24/26/28/32/40/44/60/64）收敛到 **≤5 档**（12 元信息 / 16 正文 / 20 导航 / 24 展示 / 40+ 空态）；
- 所有可点元素具备 `:active` 反馈且**不位移**；
- 全局支持 `prefers-reduced-motion: reduce`（关闭过渡与动画）；
- 正文 / 摘要 / 元信息对比度保持 ≥4.5:1（现状 `#606266` 对白底 6.11:1，达标，不引入更弱色）。

## 2. 范围

- **做**：
  - 图标尺寸令牌化：`13/14/15 → 16`（或就近 12）、`18 → 20`、`22/26/28 → 24`，`40/44/60/64` 归入展示 / 空态档保留；逐处替换 `:size`；
  - `tokens.css` 补 `:active` 反馈（按钮 / 链接 / 列表行，用 opacity 或背景加深，**不位移**）；
  - `tokens.css` 补 `@media (prefers-reduced-motion: reduce)` 全局关闭过渡与动画；
  - 在 [CR-158 方案](./CR-158-首页与列表视觉识别度.md) §7 加注披露：`--cl-text-regular` 与 `--cl-text-meta` 同为 `#606266`，故 CR-158 ⑤「摘要降一档灰」**无视觉变化**，层次实际靠标题字重 / 字号；摘要保留 `text-ink-meta` 作语义标记。
- **不做**：
  - 间距 `mt-1.5`(6px) / `mt-0.5`(2px) 清理（29 处，非 4 倍数但视觉回归风险高，**单独评估**）；
  - 换主色 / 换字体 / 引入新的更弱文字色（AA 4.5:1 底线已压缩颜色层次空间）；
  - 移动端触摸目标扩大（需逐页实测 hit area，单独 CR）；
  - 不改后端、接口契约、数据库。
