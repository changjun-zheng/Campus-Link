## 1. 目标

CR-215 交付的审计页只能按动作 / 操作者 / 时间筛，追查「某条帖子 / 某个用户被处置过几次」要人工翻页；治理留痕也缺一个可离线归档的出口。本 CR 在同一条只读链路上补**目标对象筛选**与**CSV 导出**，不动审计写入、不改动作词表、不新增错误码。

## 2. 范围

- **做**：
  - `GET /api/v1/admin/audit-logs` 新增 `targetType`（≤32 字，去空白，空串不筛）与 `targetId` 筛选。
  - 新增 `GET /api/v1/admin/audit-logs/export`（仅 SUPERADMIN，`text/csv`）：复用同一组筛选；UTF-8 BOM；RFC 4180 引号转义；**公式注入防护**（首字符为 `= + - @ \t \r` 时前置 `'`）；上限 **5000 行**，超出 → `400 / 1001`；文件名 `audit-logs-<UTC 时间戳>.csv`；`Cache-Control: no-store` + `nosniff`。
  - 管理后台审计页：目标类型下拉（可手输）、目标 id 输入、导出按钮（遵循当前筛选）。
  - 单测、契约快照重抓、技术方案 §5、台账 / 驾驶舱 / 文档索引同步。
- **不做**：
  - 不新增审计写路径（导出是读操作，不写 `AUDIT_EXPORT`）；不改 25 个动作名与既有出参形状。
  - 不做异步大文件导出、导出任务表、Excel/xlsx；不做按目标类型聚合统计。
  - 不改 `audit_logs` 表结构（V14 索引已覆盖时间与动作，目标筛选量级可接受）。
