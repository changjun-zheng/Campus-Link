## 1. 目标

新建／编辑帖子可上传截图并插入 Markdown，支持草稿恢复、预览、发布、详情与封面。本地磁盘、受控读取、本机先行且生产禁用。

## 2. 范围

单文件选择，JPEG／PNG 输入及处理后均 ≤2MiB，宽高分别 ≤4096px；每帖最多 10 张本地图片，每人每小时最多尝试 20 次，最多并发解码 2 个。不做回帖上传、粘贴／拖拽、裁剪、对象存储、图像审核、文件自动清理；不改头像，保留 HTTPS 外链。公开响应／地址不包含文件原名、上传人 ID 或磁盘路径。

## 3. 改动点（文件级）

- `module/forum` 四层：元数据、存储／频控端口、应用服务、Controller，发帖／编辑事务绑定及回帖引用阻断。
- `common/markdown/MarkdownRenderer.java`：先补安全用例再扩展严格路径白名单与净化后引用／封面提取；`V12__post_images.sql`；配置、生产守卫。
- `PublishView.vue`、前端 API 与展示组件：上传、JWT 读取、Blob 预览、草稿与生命周期；详情／封面适配。
- 测试；PRD、技术方案、ER、契约、UI 规范、验收、索引、台账与驾驶舱同步。

## 4. 步骤

1. upload-enabled／read-enabled 开发均 true，上传要求读取；生产均 false 且守卫阻断任一开启覆盖。禁传 403、禁读 404。元数据含 UUID、所有者、单一所属帖子、正文引用标记、UPLOADING／READY／FAILED、内部键、格式／大小／尺寸／UTC 时间。
2. 受保护 POST /api/v1/post-images（multipart file），登录且账号可发布；频控／并发先于解码，魔数＋实际解码检查，拒绝伪装、SVG／GIF／WebP、超限尺寸。JPEG／PNG 按原比例重编码、去元数据，PNG 留透明度，不纠正 EXIF 方向。先登记再落盘，成功标 READY，失败留记录且不可读。返回 ApiResponse<{id,url,width,height,size}>，不保留原文件。
3. Markdown 用 /api/v1/post-images/{UUID}/content；仅新增该严格相对路径，拒绝 HTTP、//、data／javascript／blob、穿越。净化后实际 img 提取引用，代码块不算。绑定与帖子事务一致，校验 READY／归属／数量／单帖；移除只取消公开引用，不删除文件／记录。封面取净化后的首张合法图片，兼容 HTTPS，不批改旧帖。
4. GET /api/v1/post-images/{UUID}/content 返回二进制；未绑定／未引用仅所有者可读；被引用按帖子及请求登录态判可见，复用删除／下架／拉黑／举报。绑定帖子不可见后所有新请求统一 404。no-store、Vary: Authorization、nosniff，无静态旁路／重定向／URL 令牌，已下载不可撤回。
5. 上传中显示状态、暂停正文编辑与提交，成功在原选区末尾插入 ![图片](url)，失败原文不变，离页取消且忽略迟到结果。草稿只存规范 URL；预览／详情／封面带 JWT 读取，本地 src 注入预览 DOM 前转 Blob，替换／退出释放，不写回 Markdown、不重渲染或前端净化兜底。
6. 复用 1005/413、4001/401、4002/403、3001/404；新增 3004/422 非法图片、3005/429 频控／并发、3006/422 非法引用、3007/503 存储故障。错误由全局出口；补端点及发帖／编辑／回帖声明、重抓快照。维护说明含容量与未引用文件排查，无自动删除。

## 5. 验证

安全：格式伪装／损坏／体积像素上限／去元数据／透明度／存储失败／穿越和既有 XSS。权限与事务：匿名上传 401、封禁拒绝、本人草稿可读而他人／匿名 404、盗用／跨帖拒绝、并发绑定和回滚。生命周期：发布、移除、下架／删除／恢复、匿名不泄露作者。浏览器：选图→预览→发布→详情封面→编辑预填→替换／移除→回跳；草稿刷新、失败原文、重复提交、离页取消，375／768／1024／1280／1440 无溢出。完整 mvn verify、真实 Flyway、前端三项、文档一致性、预期契约差异、匿名发帖 401；真启动证明生产覆盖被拒。证据集中、不预设测试数。

## 6. 回滚

开发先禁传留读，已有引用可显示和编辑，不可新增绑定；回退读取前处理已发布引用。保留表、记录、文件，不改旧迁移、不自动删除。生产始终关闭，后续开放须另定图像审核策略并登记。

## 7. 实施结果

- 已完成本地 JPEG／PNG 重编码、元数据记录、事务绑定、受控读取及编辑器／详情／封面接入；V12 已真实迁移成功，生产覆盖开启被启动守卫拒绝。
- `SPRING_IT=true` 标准 `mvn verify`：835 项、0 失败、0 跳过；覆盖率、SpotBugs、Checkstyle 通过；前端构建／类型／静态检查及文档一致性通过。
- OpenAPI 真实重抓：新增两操作，发布／编辑／回帖仅预期错误声明变化；75 操作、65 路径；匿名发帖和上传均为 401。
- 浏览器通过上传→草稿恢复／预览→发布→详情／封面→编辑移除→回跳；五断点布局、失败正文保留、上传禁用提交及离页取消均有证据。
- 真实接口覆盖他人草稿、盗用／跨帖、回帖拒绝、下架／恢复／删除及格式／大小拒绝；PNG 文本和 JPEG EXIF 元数据移除实测通过。
- 证据及维护入口：[帖子图片验收与维护](../帖子图片验收与维护.md)。受控故障／延迟模拟与真实接口结果分别注明，未进行多浏览器、屏幕阅读器和生产部署；SSE 未复测。
