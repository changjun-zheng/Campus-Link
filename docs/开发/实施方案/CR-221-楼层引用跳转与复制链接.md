## 1. 目标

CR-219 去掉了楼层号、CR-220 让 `?floor=<replyId>` 深链在长贴里可靠，但读者仍缺两个入口：引用块是静态摘要，点不回去；普通读者也无法获得某一层的可分享地址。本 CR 只补前端交互：引用块点击跳到被引楼层（同页滚动、跨页复用 `focus` 由服务端定位），楼层操作行新增「复制链接」产出 `/post/{id}?floor={replyId}` 深链。

## 2. 范围

- **做**：
  - 引用块改为按钮：点击 `jumpToQuotedReply(r)`；被引楼层在当页则直接滚动 + 高亮，不在当页则 `loadReplies(replyId)` 由服务端返回所在页后再滚动 + 高亮；目标已不可见（已删 / 下架 / 被过滤）时提示「被引用楼层已不可见」，不报错。
  - 楼层操作行新增「复制链接」（公开可用，不要求登录）：复制 `origin + router.resolve(...)` 得到的 `/post/{id}?floor={replyId}`，成功 / 失败 toast。
  - 抽 `frontend/src/utils/clipboard.ts`（`copyText`），`utils/copyCode.ts` 与 `composables/useAssistant.ts` 改为复用，消除三份重复的剪贴板实现。
- **不做**：
  - 不改后端、不新增接口参数、不重生成契约（`focus` 由 CR-220 提供，本轮零契约变化）；
  - 不改楼层排序 / 分页口径，不做翻页状态入 URL；
  - 不恢复楼层号展示（CR-219 口径不变）。

## 5. 验证

- **交互**：引用块 hover 有可点击反馈；点击同页目标只滚动不重载（观察请求数）；跨页目标按响应 `page` 同步分页器后高亮；`cl-floor-focused` 落在正确楼层。
- **剪贴板**：浏览器授权下复制成功 toast 且剪贴板内容为完整深链；拒绝授权时降级成功或给出失败提示（不静默）。
- **回归面**：代码块「复制」按钮、AI 回答「复制」按钮行为不变（同一 `copyText`，成功 / 失败文案与计时逻辑不动义）；`?floor=` 直达定位行为与 CR-220 一致。
- **静态门禁**：`lint` / `typecheck` / `build` 全绿；无后端 / 契约变化，`mvn verify` 基线不受影响（1010）。

## 6. 回滚

纯前端改动，回滚 = revert 本 CR 提交；无迁移、无接口、无数据影响。若只想撤交互，可单独回退 `PostDetailView.vue`，`clipboard.ts` 与两处复用改造可保留（行为等价）。

## 7. 实施结果

- 前端：新增 `utils/clipboard.ts`（`copyText`），`copyCode.ts` / `useAssistant.ts` 改复用；详情页抽 `focusFloor(id)`，引用块改原生按钮接 `jumpToQuotedReply`，操作行加「复制链接」接 `copyFloorLink`（`router.resolve` 生成深链）。零后端 / 契约 / 迁移变化。
- 静态门禁：`npm run lint` / `typecheck` / `build` 全绿；后端零改动，`mvn verify` 基线沿用 1010（本轮未重跑）。
- 浏览器实测（headless Edge + CDP，27 回复两页帖）：第 2 页点同页引用块 → 目标楼层高亮且**无额外 /replies 请求**；点跨页引用块 → 发出 `focus=4169` 请求、分页器回到第 1 页、目标高亮且入视口；点「复制链接」→ 剪贴板精确等于 `http://localhost:5173/post/400178?floor=4193`、toast 出现；打开该深链 → 第 2 页、目标高亮。全程零 4xx / JS 异常。证据 `backend/target/cr221-quote-jump.png` / `cr221-copy-link.png` / `cr221-deep-link.png`（测试产物，未入仓）。
- 未测：被引楼层在点击前被删除 / 下架时的提示分支（需破坏测试数据；代码与服务端回落口径同 CR-220，风险低）；代码块复制与 AI 复制仅做静态门禁，未重复浏览器点击。
