# CR-204 首页滚动与返回体验（UI-03）

| 文档信息 | 内容 |
|---|---|
| 版本 | v1.0 |
| 状态 | 已实施（结果见 §7） |
| 维护人 | 前端（发起人兼任） |
| 最后更新 | 2026-11-07 |

## 1. 目标

首页「滚动找帖 → 进入详情 → 返回」后，排序、已加载条数与滚动位置全部丢失：组件重新挂载会把排序重置为「最新」、列表退回第一页、中栏滚动归零。本 CR 补齐这条返回链路，并让「切换排序」稳定回到列表起点。

## 2. 范围

**做**：`HomeView` 的列表状态记忆（排序 / 已加载条数 / 滚动位置）与恢复；排序切换回顶；失败回退；1440 / 1024 / 768 三档同一任务实测。

**不做**：不切换滚动方案——现状已是 lg+ 中栏独立滚动、<lg 整页滚动（CR-100 / CR-091 / CR-174），本 CR 保留该结构；不引入 `KeepAlive`；不改路由全局 `scrollBehavior`；不改接口、后端与数据；不覆盖版块 / 搜索页的返回（另议）。

## 3. 改动点（文件级）

- `frontend/src/views/HomeView.vue`：
  - **保存**：离开首页时把 `{sort, loaded, scrollTop, windowY, ts}` 写入 `sessionStorage`（键 `campuslink:home:list`）。lg+ 记中栏容器 `scrollTop`，<lg 记 `window.scrollY`。
  - **恢复**：仅在「上一页是帖子详情」（`history.state.back` 匹配 `/post/`）且快照 ≤30 分钟时恢复；先按快照 `sort` 拉 `size = min(loaded, 100)`（后端页大小上限 100），`nextTick` 后设置滚动位置；其余入口（点 Logo、导航回首页）一律从顶部开始。
  - **排序切换**：`watch(sort)` 里在中栏容器与 `window` 两处都回到顶部（现有仅热榜「更多」路径回顶）。
  - **失败回退**：恢复请求失败或快照非法 → 清除快照并按默认「最新 + 第一页」加载，不阻塞页面。
- **边界**：`size` 超过 100 时只恢复前 100 条，其余由现有触底续载补上；不新增依赖、不改样式。

## 4. 步骤

1. 抽保存 / 读取 / 校验三个小函数，先落「保存 + 恢复」主链路。
2. 接排序切换回顶，处理首次挂载不误触发。
3. 1440 / 1024 / 768 三档实测：滚动 → 进详情 → 返回；点 Logo 回首页；切换最新 / 热门 / 关注。
4. 回归触底续载（不重复追加）、失败重试、窄屏整页滚动。

## 5. 验证

- 任务式验收：滚动到第 20 条以后 → 进入详情 → 返回，排序、条数、位置一致；返回后点热门，位置回到列表顶部。
- 对照：直接点 Logo 回首页应为顶部第一页（不恢复）。
- 触底续载不重复追加、失败可重试；无 console / page error。
- `npm run lint` / `typecheck` / `build` 全 exit 0；`check_docs_consistency.py` exit 0。

## 6. 回滚

纯前端逻辑，无接口 / 数据 / 迁移；整笔 revert 即恢复现状（返回丢状态）。

## 7. 实施结果（实施后追加，不回改上文）

- **交付**：`HomeView.vue` 增加列表状态记忆——离开首页去帖子详情时把 `{sort, loaded, scrollTop, windowY, ts}` 写入 `sessionStorage`，回首页 setup 期同步读取（排序与页大小先于首次加载确定，避免 `watch(sort)` 触发二次请求），消费一次即清；只去非详情页的离开一律丢弃快照。
- **实现取舍（与原计划的差异）**：计划写「按已加载条数分批补齐」，实际改为把本批页大小临时放大为 `min(loaded, 100)`，一次请求取回；后续批次沿用同一页大小，保证 `page/size` 偏移不重不漏（后端页大小上限 100）。少发 `ceil(loaded/6)` 次请求。
- **排序回顶**：`watch(sort)` 同时对中栏容器与 `window` 归零，窄屏整页滚动同样生效。
- **验证**：1440×800 中栏容器滚动 900px、18 条状态下进详情 → 浏览器返回，`scrollTop` 900、条数 18、排序一致；切换「热门」后 `scrollTop` 0；从组队页点 Logo 回首页为「最新 + 6 条 + 顶部」（不恢复）；768 整页滚动 1002px、28 条，返回后 `scrollY` 1002、条数 28。无 console / page error；`lint` / `typecheck` / `build` 全 exit 0。
- **未测**：真实触控设备与移动端浏览器返回手势；"6 条在 1440×1000 恰好不溢出时不自动续载"属既有滚动门行为，未在本 CR 处理。
- **证据**：见本会话 Playwright 实测输出（无截图归档）。
