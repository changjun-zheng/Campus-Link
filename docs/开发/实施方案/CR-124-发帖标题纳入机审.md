## 1. 目标

1. **安全缺口**：`PostApplicationService.publish` 只对 `contentMd` 调机审，`title` 不过机审——违禁词写进标题即可绕过 F-SAFE-001。
2. **契约缺口**：`POST /api/v1/posts` 与 `POST /api/v1/posts/{postId}/replies` 在实现里已会抛 `5001 / 5002`（CR-082 起），但两个 Controller 的 `@ErrorCodes` 都未声明，归档契约只有 400/401/403/404/500。

## 2. 范围

**做**

- `publish` 在版块校验之后先审标题、再审正文；任一命中 → `5001 / 422`，网关异常 → `5002 / 503`；
- `PostController.publish` 与 `ReplyController.reply` 的 `@ErrorCodes` 补 `MODERATION_BLOCKED` / `MODERATION_UNAVAILABLE`；
- 单测：标题命中 → 5001 且不落库、正文机审不再触达；契约快照再生成（两个 operation 各增 422/503）。

**不做**

- 不改机审网关 / 词表 / 模式；不改回帖正文的既有调用链（仅补契约声明）；
- 不改标题长度 / 字符集校验；不做真实服务商适配（A3-8）。

## 4. 步骤

1. 应用服务补标题机审；
2. 两个 Controller 补错误码声明；
3. 单测 + `SPRING_IT=true mvn -o verify`；
4. 以 `MODERATION_MODE=local` + 词表真机验：标题命中 → `422 / 5001`、正常标题 → 200（验证帖删除）；
5. 契约重抓 + 台账 / 驾驶舱 / 技术方案 / 问题清单同步。

## 5. 验证

- `SPRING_IT=true mvn -o verify` 全绿（基线 524 + 新增用例），SpotBugs 0；
- 单测：标题命中 → 5001、`postRepository.save` 零调用、正文机审零调用；
- 真机：local 模式标题含违禁词 → `422 / 5001`，正常标题 + 正常正文 → 200；
- 契约：`POST /posts` 与 `POST /posts/{postId}/replies` 出现 422 / 503，机器比对通过。

## 6. 回滚

- 应用服务删除标题那一行 `moderateOrThrow`；两个 Controller 回退新增的两个错误码；
- 契约重抓回 v1.26；无迁移、无新依赖，回滚不影响既有帖子数据。

## 7. 实施结果（2026-10-23）

**与原计划一致**：`publish` 在版块校验后先审标题、再审正文；`PostController.publish` 与 `ReplyController.reply` 各补 `MODERATION_BLOCKED` / `MODERATION_UNAVAILABLE` 声明；无迁移、无新依赖。
