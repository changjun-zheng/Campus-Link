> 编号修正（2026-11-03）：本方案原以 CR-190 起草，而 CR-190 已被“图标系统 PNG → SVG 回退”占用；经发起人选定实施本项后，方案与登记统一改为 **CR-191**，正文技术口径未改。

> 本方案把 A（预置头像选择）与 B（本地上传）合并为一个 CR：两者共用「读旧值 → 校验 → 定向更新 → 审计」写路径与同一个前端弹窗。实施前停下等确认；确认后按 §4 顺序落地。

## 1. 目标

设置页头像可点击更换：① 从 8 款默认头像中选；② 上传本地 JPEG / PNG，服务端归一化后落盘并写 `users.avatar_url`。改一次全站生效（论坛列表 / 详情 / 楼层 / 通知均读时关联 `users.avatar_url`，无快照需回填）。零 Flyway 迁移、零对象存储依赖、零新第三方依赖。

## 2. 范围

- **做**：
  1. 后端：`AvatarImageGateway` 端口（domain）+ 本地磁盘适配器（infrastructure）；`Account.updateAvatar` + `AccountRepository.updateAvatar` 定向 UPDATE；`AvatarApplicationService`（限流 / 封禁门 / 预置白名单 / 上传校验 / 审计）；`UserController` 3 个端点；`/media/avatars/**` 只读静态映射；配置与错误码；单测 + 授权测试。
  2. 前端：设置页头像变按钮 → 异步 `AvatarDialog`（预设 8 宫格 + 上传预览）；`client.ts` 支持 FormData；`api/auth.ts` 3 个函数；Vite dev / preview 加 `/media` 代理。
  3. 文档：重抓契约快照；技术方案 §5、界面规范、PRD 007h 加注、台账 / README / 驾驶舱登记。
- **不做**（边界）：
  - **不接对象存储 / OSS**：端口可替换，OSS 适配器另开 CR；生产用持久卷目录。
  - **不加新依赖**：图片处理用 JDK `ImageIO`；前端不引 cropper，不做自由裁剪（服务端居中裁方）。
  - **不收动图 / 矢量**：GIF / WebP / SVG 一律拒绝（SVG 可含脚本；WebP 需额外解码库）。
  - **不做图片机审**：图片内容安全归 F-SAFE-001 后续；本轮只做格式 / 尺寸 / 重编码防线。
  - **不改默认素材与分配规则**：`DefaultAvatar` 8 款与 `userId % 8` 不动。
  - **不做旧文件批量清理任务**：只删除「本次替换掉的那一个」旧文件；孤儿文件清理另开 CR。

## 8. 实施结果（实施后追加，不回改上文）

**2026-11-03 实施完成**。§1~§6 按方案落地，D1~D8 全按默认口径执行、无改判。与计划的偏差与补充如下：

1. **dir 路径偏差修正**：配置默认值实为 `var/uploads/avatars`（相对进程工作目录，即 backend 运行目录），非 §5 / §6 字面的 `backend/var/...` 前缀写法；实际落盘位置仍是 `backend/var/uploads/avatars/`，`.gitignore` 已加 `backend/var/`。配置默认值不进契约，快照不受影响。
2. **SpotBugs 5 条**：1 条 NP_NULL **真修**（`LocalAvatarImageAdapter.store` 对 `target.getParent()` 显式判 null 抛 `AVATAR_INVALID`）；4 条 EI_EXPOSE_REP2 为 DI 构造注入同型（`AvatarApplicationService` / `UserController` / `LocalAvatarImageAdapter` / `MediaResourceConfig`），按 `spotbugs-exclude.xml` ①组先例逐条登记豁免。
3. **测试基线 758 → 779（+21）**：`AvatarApplicationServiceTest` 9（含限流 2017 / 封禁 2006 / 白名单外路径 2016）、`LocalAvatarImageAdapterTest` 7（`@TempDir`，含魔数嗅探 / 超尺寸 / 重编码断言）、`UserControllerAvatarTest` 5（含**匿名 → 401**）；`mvn -o verify` 全绿（5 SKIPPED 为既有约定），jacoco 0.80 门禁 / Checkstyle 通过。AGENTS.md 基线注释同步 779。
4. **契约快照**：73 操作 / 63 路径 / 124 schema / 20 tag / 57 受保护、227848 字节、`sha256 c8781faa…`、diff **+274 / −0 纯新增**；T1 / T2 快照测试同轮全绿；⚠️ 来源＝未提交工作区 ⇒ **提交后核对挂账**。
5. **浏览器全链路验收 16/16 PASS**（Playwright 真实栈 MySQL / Redis / 8088 / 5173）：登录 → 设置页头像按钮（aria-label）→ 弹窗预设 8 款 → 点选即生效（页头 + 顶栏 `UserAvatar` 同步）→ 上传 PNG（canvas 预览 `naturalWidth > 0`）→ 保存 → `/media/avatars/…` 生效 → 刷新回显 → 图片 GET 200 `image/jpeg` + 365 天 immutable 长缓存 → 375px 无横向溢出 → 控制台无 CSP 违规。

   - **缺陷①**：`AvatarDialog.vue` 的 `watch(() => props.modelValue)` 缺 `{ immediate: true }`——父组件 `v-if` 条件挂载时 `modelValue` 已为 true，watch 无变化不触发，预设列表永不加载（弹窗打开但宫格空白）；补 immediate 后修复。
   - **缺陷②**：`index.html` CSP `img-src` 缺 `blob:`——上传预览的 `URL.createObjectURL` objectURL 被浏览器拦截（console 抓到 CSP violation）；补 `blob:` 并加注释说明仅供上传本地预览。两项修复后重跑验收全 PASS。
