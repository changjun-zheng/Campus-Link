## 1. 目标

CR-196 只提供 USER → OPS 的升权，CR-208 / CR-209 两次明确把「OPS 降级」排除在范围外。当前运营角色一旦授予，除改库外没有回收路径——运营账号失陷或职责结束时无法撤权。本 CR 补 SUPERADMIN 专用的撤销入口，复用 CR-208 的 token 吊销水位，撤销后目标旧 token 立即失效、重新登录即为普通用户。

## 2. 范围

- **做**：
  - 新增 `DELETE /api/v1/admin/users/{id}/role`：仅 SUPERADMIN；只允许 OPS → USER，幂等（本来就是 USER 直接成功）；目标为 SUPERADMIN 返回 `403 / 4002`。
  - 撤销成功后写 `USER_ROLE_UPDATE` 审计（`role=USER`），并调用 `tokenRevocationGateway.revokeAllBefore(targetId, now)`。
  - 前端用户检索结果行：`role=OPS` 显示「撤销运营」按钮（二次确认），成功后静默刷新检索结果。
  - 单测、契约快照、技术方案 §5、界面规范 §5.9、台账与驾驶舱同步。
- **不做**：
  - 不做 SUPERADMIN 的授予 / 降级（属更高风险的权限管理，仍无接口）；
  - 不做批量撤权、撤权原因、撤权通知；
  - 不新增数据库迁移、错误码或配置项；不改升权接口既有语义。
