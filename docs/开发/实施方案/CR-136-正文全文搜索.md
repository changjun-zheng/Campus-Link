## 1. 目标

把站内搜索从「标题 + 标签」扩到**标题 + 正文 + 标签**：`posts.content_md` 新增 ngram FULLTEXT 索引，搜索 SQL 同时命中标题与正文，结果摘要围绕命中词截取 120 字，前端对标题 / 摘要做安全高亮。保持试点规模零新服务、零新依赖；PRD 中的 MeiliSearch 不在本轮落地，仍作为规模触发后的升级项。

## 2. 范围

**做**

- 新增 `V7__post_content_fulltext.sql`：`ALTER TABLE posts ADD FULLTEXT KEY ft_posts_content (content_md) WITH PARSER ngram`；
- 搜索 SQL 改为 `MATCH(title) AGAINST(...) * 2 + MATCH(content_md) AGAINST(...)` 相关度，命中条件为标题 / 正文 / `tags` LIKE 三选一；
- 搜索结果的 `summary` 改为**围绕首个命中词**的 120 字窗口（未命中则回落首 120 字），复用 `MarkdownRenderer` 的渲染 + jsoup 纯文本链路；
- 前端搜索页文案改为「标题 / 正文 / 标签」，`PostListItem` 新增可选 `highlight` 属性，用分段 `<mark>` 高亮标题与摘要（**不用 `v-html`**）；
- 契约快照重抓、技术方案 / ER / 契约 README / UI 规范 / 台账 / 驾驶舱同步。

**不做**

- MeiliSearch / Elasticsearch 接入、索引同步任务、独立搜索服务；
- 楼层正文检索、搜索建议、拼音 / 同义词、搜索热度分析、排序权重调参；
- 搜索接口路径 / 入参 / 出参形状变更（`PostSummaryVo` 一个字段都不加）。

- **全量测试**：`SPRING_IT=true mvn -o verify` → **645 / 0 failures / 0 skipped**，`BugInstance size is 0`，BUILD SUCCESS。

- **内置浏览器**：页面文案为「按标题、正文与标签检索」；结果摘要显示「…正文深处藏着唯一词：紫电青霜…」；`mark` 数量 1、文本「紫电青霜」、底色为主色 soft；标题词搜索 `titleMark=true`；点击结果进入 `/post/76` 详情成功。
- **清理**：验收帖、`post_tags` 关联与 `tags.use_count` 回退均已清理（`posts` / `post_tags` 残留 0）。

### 8.3 已知边界

- MySQL ngram 的 `ngram_token_size=2` 决定关键词下限 2 字；正文索引与标题索引分开建，标题权重 2 / 正文权重 1 是产品口径而非可配置项。
- `PostMapper.search` 仍为 `SELECT *`（拉出 `content_html`），试点规模可接受；若后续列表性能吃紧，再收窄为显式列清单。
- MeiliSearch 未引入；若全文检索 QPS / 内存成为瓶颈，按 ER §5 的扩容触发点评估切换，届时两条 FULLTEXT 索引可评估下线。
