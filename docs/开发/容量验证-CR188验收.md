## 3. 注册结果

- 名册：10,000 行，`used_user_id` 非空 10,000。
- 账号：10,000 个容量账号（昵称前缀「容量测试学生」）+ dev admin = `users 10,001`。
- 注册：**新注册 10,000 / 跳过 0 / 失败 0**；1000 个注册 token 写入仓库外临时文件，测后删除。
- 耗时与边界：顺序 API 注册（每账号 `verify-student → captcha → register`），验证码用 dev 固定码；只在本机回环。
